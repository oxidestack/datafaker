## [0.2.0] - YYYY-MM-DD

### Action required

- `strict_mode` is no longer read. A configuration that sets it sets `strict` to the same value instead. (bad6cd8)

### Features

- The `trim` option drops trailing whitespace from the output. (faker, f1b99da)

### Bug fixes

- An error raised in a nested call names the position of the call, so a caller finds it. (e13aa9f)
- Input that is not UTF-8 returns an error instead of a panic. (d0e5685)
- An error names the line of the input, as the Java library does. (1b117e7)

### Performance

- An input used twice is parsed once, so using it again is faster. (28ff2f8)

### Other changes

- The README lists every option with its default. (1ed8f92)
